# QuizUppgift
Frågespel i konsollapplikation

## Game features
- Stöd för multiplayer (2-4 spelare).
- Spela upp till 10 rundor.
- 18 frågor indelade i 3 kategorier: Programmering, Geografi och Allmänbildning. Välj ämne själv eller låt datorn slumpa.
- 2 sorters frågor, flerval och sant/falskt. Blandade svårighetsgrader: lätt (värd 10 poäng), medel (20 p) eller svår (30 p).
- Bonuspoäng för spelare som svarar rätt flera gånger i rad.
- Resultat sparas automatiskt efter varje runda.
- Topplista över de 10 bästa resultaten.
- Tidlös grafik med högkontrasttema :)
- Helt gratis, utan reklam. Endast inmatning av spelarnamn krävs - ingen krånglig hantering av personuppgifter eller användarkonto.

## Installation, kör programmet lokalt.
- Klona GitHub-repositoriet till din lokala dator. Öppna projektets solution och kör koden via kodeditorn. 

## Tech stack
- Språk: C#
- Ramverk: .NET 10.0
- Datalagring: JSON (lokala filer för frågor och highscores)
- Verktyg: Visual Studio, Git, GitHub
